Public Data API & Schema Reference

KnowYourSponsor operates on open data principles. Every statutory dataset, insolvency flag join, and change diff published across this terminal is accessible via static, unauthenticated JSON endpoints updated daily at 05:30 UTC.

Primary Ingestion & Change Endpoints

data/sponsors.json Core Register · 10MB

Complete index of all 127,716 active licensed UK sponsors. Packed as an array of compact tuples for high performance.

{
  "updated": "2026-09-09T05:30:00Z",
  "source": "UK Home Office Register of Licensed Sponsors",
  "sponsors": [
    ["Entity Name", "Town / City", "County", "Industry / SIC", ["Skilled Worker", "GBM"], "A rating"],
    ...
  ]
}

Served with gzip compression (~1.4MB over wire). Columnar tuple structure reduces memory footprint.

Integration Best Practices & Fair Use

  • Poll meta.json first: Consumers should poll meta.json to check if the updated timestamp has incremented before requesting the full 10MB sponsors.json payload.
  • Sync Schedule: Upstream Home Office registers refresh once per business day at 05:30 UTC. Polling more frequently than hourly consumes unnecessary network bandwidth.
  • Licensing: Underlying Home Office and Companies House datasets are Crown Copyright / Open Government Licence (OGL v3.0). Entity matching algorithms, solvency joins, and diff indices are provided openly with attribution requested.
